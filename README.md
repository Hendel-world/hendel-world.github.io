# 🌐 HENDEL WORLD — Сайт и Донат-Магазин

Готовый современный сайт с донат-магазином и приёмом платежей для гриферского сервера **HENDEL WORLD (1.21.4)**.

---

## 📁 Структура файлов:
* `index.html` — Главная страница сайта (каталог доната, кейсов, монет, правила, копирование IP)
* `style.css` — Тёмный RPG-стиль, неоновые эффекты, адаптивность под телефоны
* `script.js` — Логика выбора товаров, модальное окно оплаты, выбор СБП/карт/крипты
* `server.js` — Node.js бэкенд для приёма Webhook от платёжки и авто-выдачи доната в игре через RCON

---

## 🚀 Как открыть сайт прямо сейчас:
Просто откройте файл `index.html` в любом браузере (Google Chrome, Яндекс, Edge)!

---

## 💳 Как подключить реальную оплату (AnyPay / PayOK):

Для майнкрафт серверов в СНГ лучше всего подходят **AnyPay.io** или **PayOK.io** (принимают СБП, банковские карты РФ/СНГ, ЮMoney без открытия юрлица):

1. Зарегистрируйтесь на сайте [AnyPay.io](https://anypay.io/) или [PayOK.io](https://payok.io/).
2. Создайте новый проект (магазин) и укажите ссылку на ваш сайт.
3. Скопируйте **ID проекта** и вставьте в `website/script.js` в переменную `projectId`.
4. В личном кабинете платёжки укажите URL оповещения об оплате: `http://ваш-ip:3000/pay-callback`.
5. Готово! При оплате деньги поступают на ваш кошелёк/карту, а донат выдаётся игроку.

## 🖥️ Где бесплатно разместить сайт в интернете:
1. **GitHub Pages** (Бесплатно, навсегда) — загрузите файлы в репозиторий GitHub и включите Pages в настройках.
2. **Vercel / Netlify** (Бесплатно в 1 клик) — перетащите папку `website` в личный кабинет Vercel.
3. **На вашем VDS сервере** (вместе с сервером Minecraft через Nginx/Apache).
